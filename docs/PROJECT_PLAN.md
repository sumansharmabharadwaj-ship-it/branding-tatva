# Branding Tatva — Sitemap & Conversion Plan

## Site structure
```
/               Home
/about          About Suman
/services       Services (elemental system)
/work           Work (portfolio index)
/work/[slug]    Individual case studies
  /work/myshopineurope
  /work/executive-springboard
  /work/dr-haley-nutrition
  /work/herbalcart
  /work/plaxonic-content-portfolio
/contact        Contact
/privacy        Privacy Policy
/terms          Terms of Use
/404            Custom not-found page
```
Architecture leaves room for `/insights` later without restructuring anything.

## Primary conversion
A visitor submits a project enquiry through the Contact page.

## Secondary conversions
- Browses Work / opens a case study
- Reads the Services page fully
- Reads About
- Downloads résumé
- Clicks through to LinkedIn/Instagram
- Emails directly
