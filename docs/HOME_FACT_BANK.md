## Copy integrity checks

Before a homepage claim ships:

1. Can it be traced to `src/data/site.ts`, `src/data/projects.ts`, another documented source, or direct user confirmation?
2. Does it preserve the difference between strategy delivered and business result achieved?
3. Does it avoid implying causation beyond the evidence?
4. Does the CTA destination actually perform the promised next step?
5. Would the user be comfortable defending the sentence to a prospective client?

If any answer is no, rewrite or remove the claim.
