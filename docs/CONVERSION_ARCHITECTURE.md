# Conversion Architecture (Suman's brief, Aug 3, 2026 — governs Home/About/Services structure)

Core sequence change: Philosophy→education→proof→offer→booking BECOMES Relevance→proof→offer→philosophy→risk removal→booking.
First two sections of any page must answer: what, for whom, which situation, why Suman, next action. Framework never delays proposition.
Primary CTA: "Book a Brand Strategy Session". Secondary: "Explore the Work". Contextual variants per page (Work: "See the decisions behind the result"; Framework: "Find the weakest brand decision"; Services: "Explore the right service path"; Health check: "See what your answers suggest"; About: "Work directly with Suman"). Banned: Learn more / Discover / Get started / Explore now.

HOME order: Conversion hero (headline "Most brands are visible. Very few are remembered." + plain proposition line + both CTAs + verified proof + "Led directly by Suman") → Visitor recognition (3 selectable states: building from idea / exists but inconsistent / grown beyond position → need + path + CTA; persist selection locally) → Verified work early ("What changed when the brand became clearer.", 1 dominant + 2 secondary) → Why Suman (credentials as source of working perspective) → 3 service paths (Build foundation / Reposition / Ongoing consistency) → Five decisions ("Every remembered brand makes five decisions." — elements teach after proof; fix desktop/mobile dual-render) → Process (6 stages, scannable) → 4-5 essential FAQs → calm booking ("The first conversation should create clarity, even when the project begins later.").

ABOUT order: Authority hero ("Branding sits between what people notice and what they remember.") → Point of view ("A logo can be copied. A position has to be understood." + 3 principles: perception precedes preference / language frames value / consistency creates memory) → Why the practice exists (noticed / market got wrong / built to examine) → Psychology×Language convergence (fields overlap → Brand strategy; practical implications each) → Working directly with Suman (leads every engagement, direct communication, documented decisions, explained feedback, strategy precedes expression) → Evidence (projects as ambiguity→decision→observed result) → Behaviours as values ("Say less when proof is absent" etc.) → Personal closing ("Bring me the version of the brand that currently feels difficult to explain." CTA "Start the conversation").

SERVICES order: Hero ("The work begins wherever recognition is breaking down." + 3 paths above fold) → Choose your situation (main conversion mechanism; recommended package + why + scope + CTA) → Packages fully visible (who/decision/scope/deliverables/duration/client provides/next step; never fake "most popular") → One verified case (starting condition/decision/execution/measured change) → Weak branding cost (shortened, toggle generic↔distinct, keyboard accessible) → Recognition ladder (stages tied to service decisions + "Which stage sounds closest?" updates recommendation) → Deliverables grouped by outcome (Foundation/Expression/Activation/Continuity) → Health check (result recommends package) → Right fit FAQ → What happens on the call → Booking (≤2 optional questions, skippable to calendar).

LEAD SYSTEM: Primary = booking. Secondary lead magnet = "The Brand Recognition Audit" (positioning clarity Qs, distinctive asset review, verbal identity review, consistency check, one page worksheet — no generic ebook). Fields: first name, email, business optional; explicit consent; no phone. Health check result emailable AFTER useful preview shown. Persist locally: situation, ladder stage, health answers — personalization only, no dark patterns.

NAV: Work / Services / About / Insights / Book a Session (distinct). Compact on scroll.
MEASUREMENT: events for hero booking click, case click, situation selected, package viewed, health start/complete, email result, FAQ open, calendar open, booking complete. Funnel: visit→path→service→booking opened→completed. No conversion claims without measurement.
IMPLEMENTATION ORDER: P1 Home restructure → P2 Services restructure+connections → P3 About → P4 lead magnet+capture+events. Validate with 6 visitor scenarios; 10-second comprehension test; three widths each page.
BANS: fabricated scarcity, fake social proof, countdowns, first-arrival popups, excessive forms.
