# The one directing system (Suman's review, Aug 2026) — GOVERNING

Her diagnosis: the site accumulated patches instead of one directing
system. Many components each try to create atmosphere alone, so every
instrument plays the solo. This document is the replacement standard.
It outranks any single component's own history.

## The seven systems (one each, no exceptions)

navigation · motion language · video · cards · pills · transition
grammar · conversion hierarchy.

Before adding any effect, name which of the seven it belongs to. If it
belongs to none, it does not ship.

## Home flow (the required order)

Hero → recognize your situation → verified proof → how Suman thinks →
relevant service path → Tatva framework → process → booking.

Philosophy earns its place only after commercial relevance.

## Pinning budget

One major immersive sequence on Home, one on Services, one signature
sequence on Work. Ordinary editorial scrolling everywhere else. A
normal wheel movement must visibly change the screen.

## Video rule: footage argues, never decorates

Every visual performs a job. Positioning = market terrain. Customer
journey = a flowing route. Brand layers = a system assembling.
Recognition = repeated signals becoming memorable. Process = a visible
project path. Case study = documentary evidence. Nature behind a
heading proves nothing and gets cut.

## Persistent layer (cockpit syndrome)

Keep: one adaptive header, one optional sound control, one contextual
chapter indicator inside genuinely long scenes. Everything else lives
in the page rather than floating above it. (Done: the brand badge and
cursor illumination are removed sitewide.)

## Framework rule

Each element must connect: business question → strategic decision →
deliverable → market consequence → related service, plus what weakens
when it stays unclear.

## Removed / replaced

Out: decorative video, duplicated ambient effects, excessive pinning,
hard seams, empty brown sections, generic marquees, repeated proof,
uninformative hover, floating controls.
In: decision maps, annotated evidence, responsive diagrams, useful
comparisons, project artifacts, contextual recommendations, match cuts,
progressive disclosure, direct booking paths.

## Sprint order

Foundation (tokens, nav, video, cards, pills, transitions, reduced
motion, mobile, CTA hierarchy) before isolated sections. Then Home:
adaptive navigation, hero hierarchy, situation selector, early proof,
evidence archive, compressed framework, process experience, booking.
