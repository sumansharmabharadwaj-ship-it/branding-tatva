# Homepage opening intent and reading

## Change

The opening word entrance now has one cancellation owner. Scroll, wheel, touch, pointer, keyboard, focus, text selection and backgrounding consume a pending entrance as well as cancelling one already running. This closes the race where interaction before the prelude finished could still be followed by a delayed headline animation.

The existing nine semantic word nodes retain their finite entrance, including the shorter travel on compact screens. Restored scroll, an existing selection, focus within the opening, a hidden document and reduced motion keep them static. An unavailable element animation API falls back to the unchanged text. Cleanup removes the listeners and cancels active animations.

Keyboard focus or input settles the opening camera, film, light, signature, headline ink, proof glint and link decoration. The existing priority poster replaces the film while reading is still. Pointer input restores the scene motion profile without replaying the headline. Native fragment links and the case study destination remain mounted. Keyboard access also overrides the prelude's temporary hiding of the proof and continuation controls.

The proof headline now reads "A clearer message. A recorded change in response." The previous "Fewer posts" line sat directly above a LinkedIn engagement comparison, while the documented posting reduction belongs to Instagram. The LinkedIn values, dates and proportional bars are unchanged. The case study link disables speculative prefetching.

## Verification

- TypeScript, changed-source ESLint and whitespace checks passed.
- Production build passed and generated 106 routes.
- A hook harness exercised eight intent paths before the prelude and the same eight during the running entrance. Pending animation never began later, and active animations cancelled.
- Four start guards passed: restored scroll, existing focus, existing selection and a hidden document.
- Prehydration cancellation, initial pause, pause during animation, compact travel, unavailable animation support, pending Strict Mode effect replay and listener cleanup passed.
- The actual opening callback checks retained all link identities while switching to keyboard reading. The camera, light and signature settled, the poster replaced the film, and pointer resumption did not repeat the title entrance.
- Three React and Framer Motion server renders covered full motion, keyboard reading and reduced motion. Each retained one heading, nine word nodes, the existing destinations and all four recorded date/value labels. Only full motion rendered the mocked film component.
- Source comparison confirmed that the recognition and hidden-cost implementations were unchanged.

The hook tests mock browser events, selection and the animation API. Server rendering checks actual markup with a mocked film provider. These checks do not certify native animation timing, focus painting, responsive layout or media playback.
